### Reconnect cross-check (not part of the fixed §7.1 oracle, recorded for completeness)

Each tuple's reconnect used `get_service_dependencies` for `service:order-service`, not a fixed
prompt, so exact call shape is not required to match. Three of four (Codex CLI, Claude Code, Cursor)
used the qualifying window and returned the same 4 dependency claims (`unused-q`
`NOT_OBSERVED_IN_WINDOW`, `legacypricingservice` `OBSERVED_ONLY`, `payment-service`/`product-service`
`CONFIRMED`); VS Code's Copilot Chat defaulted to "today" as the observation window (not told one for
that specific call) and returned 3 claims, all `NOT_OBSERVED_IN_WINDOW` for that window — a valid,
well-formed AIP response for a different (and less rich) observation window, not a semantic mismatch,
since spec §6.11 only requires tool discovery plus one successful read-only call at reconnect, not the
same window or the §6.9 deterministic result (see `vscode.md`). All four returned the same pinned
`snapshot_id` and confirmed `producer.build_revision`.
